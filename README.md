Draftline is a Krillion Style trivia game for NASCAR.
The goal is to provide the rarest (or "most niche") answer to the prompt provided, with scores increasing for increasingly rare answers.
There are 7 prompts to answer per round and you have 25 seconds to answer each prompt.

The prompt topics were created by myself and the data was sourced in R using Kyle Grealis's nascaR package.

The data was cleaned and handled in R and the prompts were written and constructed in R as well, with some AI assistance.

The .html used to create the game was created fully by an AI LLM (specifically Gemini's Hydrogen model)

The game can be played at: https://ryan-c-chandler.github.io/draftline/
More information about the nascaR package can be found here: https://kylegrealis.github.io/nascaR.data/reference/series_data.html
